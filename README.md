# Tasks for Today Management System

Built with CodeIgniter 4.

## Pages

- `/` - Welcome (only today's tasks)
- `/tasks` - Task List (all tasks, ordered by date)
- `/profile` - Profile (the demo user)
- `/about` - About (developer)

## Setup (XAMPP)

1. Put the `TSA1` folder in `C:\xampp\htdocs`.
2. Start Apache and MySQL.
3. Import `tasks_db.sql` in phpMyAdmin.
4. Open `http://localhost/TSA1/public/`.
